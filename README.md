
Fase 1: Fundamentos del lenguaje (Semanas 1 - 3)

• Instalación y entorno: Descarga Python desde Python.org e instala un editor de código como Visual Studio Code o PyCharm.
• Sintaxis básica: Aprende a imprimir en pantalla, usar comentarios y gestionar la consola interactiva.
• Variables y tipos de datos: Números (int, float), textos (str) y booleanos (bool).
• Operadores: Aritméticos, de comparación y lógicos.
• Control de flujo: Condicionales (if, elif, else) y bucles (for, while).
• Mini-proyectos: Una calculadora básica, un juego de adivinar el número.

Fase 2: Estructuras de datos (Semanas 4 - 6)

• Listas y tuplas: Almacenar, modificar y recorrer colecciones ordenadas de datos.
• Diccionarios y conjuntos (Sets): Manejar datos clave-valor y elementos únicos.
• Mini-proyectos: Una agenda de contactos o un inventario de tienda.

Fase 3: Funciones y modularidad (Semanas 7 - 8)

• Definición de funciones: Uso de def, parámetros, argumentos, valores por defecto y el comando return.
• Ámbito de variables (Scope): Variables locales vs. globales.
• Funciones avanzadas: Introducción a funciones lambda y comprensión de listas (list comprehensions).
• Mini-proyectos: Un convertidor de unidades o un sistema de facturación con funciones.

Fase 4: Persistencia y manejo de archivos (Semanas 9 - 10)

• Archivos de texto: Leer y escribir archivos .txt.
• Formatos de intercambio: Trabajar con archivos JSON y CSV.
• Bases de datos básicas: Introducción a SQLite con Python.
• Mini-proyectos: Un registro de gastos diarios que guarde la información en un archivo JSON o base de datos.

Fase 5: Programación Orientada a Objetos - POO (Semanas 11 - 13)

• Clases y objetos: Definir moldes, atributos y métodos.
• Pilares de la POO: Herencia, encapsulamiento y polimorfismo.
• Manejo de errores: Bloques try, except y finally para evitar que el programa se cierre inesperadamente.
• Mini-proyectos: Un sistema de gestión de biblioteca o un simulador de banco con clases.

Fase 6: Especialización y Librerías (Semana 14 en adelante)

Elige un área de enfoque según tus intereses:
• Desarrollo Web: Flask o Django.
• Ciencia de Datos / Inteligencia Artificial: NumPy, Pandas, Matplotlib.
• Automatización / Scraping: Selenium, Requests, BeautifulSoup.
